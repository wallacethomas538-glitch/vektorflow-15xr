# VektorFlow BYOK Gateway

Open-source API gateway where users bring their own API keys. Zero cost to you, infinite scaling.

## Features

- **BYOK Architecture** – Users pay for their own usage
- **Voice Input** – Speak API keys on supported browsers
- **Multi-Provider** – Groq, OpenAI, Mistral, Google, Cohere
- **OpenAI Compatible** – Drop-in replacement for OpenAI API
